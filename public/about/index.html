about

Hello, my name is Joe.

For as long as I can remember, I have had an interest in taking things apart, figuring out how they work, and putting them back together. It started with Nerf guns as a kid, then grew into DIY electronics projects in high school, and then cars when I was old enough to drive.

Since I was born at a time when technology was less prevalent, I had a lot of interest in that as well. But I did not like the idea of sitting behind a computer all day for a job. I enjoyed working with my hands too much.

That's what makes my skills unique. Rebuilding a pump, troubleshooting a die set, replacing a motor? Sure. Problems with automated equipment; PLC, sensors, solenoids? Sure.

What I work on

  • Automated equipment
    • Complete rehabilitation to fine tuning
    • Using Allen Bradley/Rockwell PLC devices
    • Fanuc robots
    • Occasional Cognex vision systems
  • Tooling
    • Troubleshooting, maintaining, cleaning, and sharpening stamping dies used to manufacture lithium thionyl chloride batteries
    • Designing new parts to upgrade or retrofit older equipment
    • Designing hard gauges for part or subassembly inspection
  • Laser Welding
    • Weld schedule development
    • weld cross-sectioning, preparation, and penetration measurement
    • Nd:YAG laser maintenance and repair (LASAG)
    • Hermeticity testing using helium mass spectrometer leak detectors
  • CAD
    • Solidworks, primarily
    • AutoCAD
    • Autodesk Fusion/Fusion360, for home projects
    • Autodesk Inventor, in high school, but all CAD programs are very similar
  • Python
    • Wrote scripts utilizing Pandas and MatPlotLib to filter, analyze, generate graphs, and compile results for battery runtime test data, recorded using an oscilloscope, and using a custom LabVIEW data acquisition system

Outside of work

Hobbies, interests, etc.

  • 3D Printing; fused deposition modeling (FDM), using PLA, PETG, ASA, ASA-CF filaments
  • Autocross, with Philly SCCA mostly
  • Self-Hosting/NAS; DIY network attached storage (NAS) running Unraid, which serves as my home file storage system, as well as running Home Assistant VM, and several other Docker containers
  • Smart home projects using Home Assistant VM, Zigbee devices, Z-Wave devices, and making custom devices using ESP32's and ESPHome
  • Photography; digital and film
  • Fixing lawnmowers, weedwackers, snowblowers, anything that has a carburetor
  • Modifying, fixing, working on cars in general
  • Mechanical keyboards, which lead to keyboard design, PCB design, soldering, silicone molding, and resin casting
